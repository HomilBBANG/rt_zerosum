# 결정 로그 v1.0

## 확정
- Godot 4.7, 횡스크롤 턴제, 6인(전방/중앙/후방 2슬롯씩), 수동 전투 우선, 자동 모드 알파 이후.
- 기습/매복 선공 우선, 일반 전투 동전, 선공은 첫 라운드 최초 행동에만 적용, 이후 양 진영 속도순 및 지정된 동률 우선순위.
- 캐릭터 자기 차례에 스킬/대상 지정 및 AP 내 다중 행동. 전투 시작 최대 AP, 자기 차례 회복, 최대 AP 상한, AP 이월, 0 AP 자동 종료.
- 모든 행동 AP 소모, 무기 변경 AP 1.
- 자기 차례 캐릭터만 이동 명령 가능. 빈 슬롯 이동, 점유 슬롯 아군과 교환.
- 단순 셀 셰이딩, 미국 카툰풍, 5번 이미지 캐릭터 화풍 목표, 광원별 강렬한 원색 대조.
- 최종 수치 밸런스는 관련 시스템 구현 후 진행.

## 프로토타입 임시 설정

  **전투 기록은 2단**: 1단 = 우측 상단 아이콘만(글자 없음), 2단 = 아이콘 아래 기록 창(기존 크기). 아이콘 클릭 또는 L.

  - AP 는 버튼을 누를 때가 아니라 **행동을 실행할 때** 소모 (대상 클릭·자리 클릭·장착하기).

  - 상태 이상은 슬롯 오른쪽, 채도 낮은 불투명 파란 외곽선 창 안에 **한 줄씩**: 긍정 녹색 / 부정 붉은색, 호버 시 그 줄 50% 밝게(페이드) + 설명.
    현재 상태 이상: 독려(긍정, 독려 받은 유닛의 다음 턴 끝까지), 부상(부정, 자리 이동·교체 불가 — 아직 거는 스킬 없음).
  - 사용할 수 없는 슬롯은 회색, 비용은 "-AP" (사용 불가 붉은색 / 가능 파란색).
