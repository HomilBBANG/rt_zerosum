# 결정 로그 v1.0

## 확정
- Godot 4.7, 횡스크롤 턴제, 6인(전방/중앙/후방 2슬롯씩), 수동 전투 우선, 자동 모드 알파 이후.
- 기습/매복 선공 우선, 일반 전투 동전, 선공은 첫 라운드 최초 행동에만 적용, 이후 양 진영 속도순 및 지정된 동률 우선순위.
- 캐릭터 자기 차례에 스킬/대상 지정 및 AP 내 다중 행동. 전투 시작 최대 AP, 자기 차례 회복, 최대 AP 상한, AP 이월, 0 AP 자동 종료.
- 모든 행동 AP 소모, 무기 변경 AP 1.
- 자기 차례 캐릭터만 이동 명령 가능. 빈 슬롯 이동, 점유 슬롯 아군과 교환.
- 단순 셀 셰이딩, 미국 카툰풍, 5번 이미지 캐릭터 화풍 목표, 광원별 강렬한 원색 대조.
- 최종 수치 밸런스는 관련 시스템 구현 후 진행.

## 프로토타입 임시 설정

- 그래픽 표현은 **2D** 로 확정 (2D/3D 비교: `docs/2D_vs_3D_comparison.md`). 캐릭터 3D 전환 기능(Tab·메뉴 표현 모드)은 제거 (2026-10-26).
- 전투 HUD (2026-10-26): 상단 바 검은 배경 제거, **행동 순서는 상단 중앙의 초상화**(호버 시 이름, "행동 순서" 글자 없음), **차례 유닛 초상화 30% 확대**.
  **전투 기록은 2단**: 1단 = 우측 상단 아이콘만(글자 없음), 2단 = 아이콘 아래 기록 창(기존 크기). 아이콘 클릭 또는 L.
  동전 결과 글자는 HUD 에 표시하지 않음. 글꼴은 **Pretendard** (Regular/Medium/Bold, OFL).
- 발밑 표시 (2026-10-26): 체력(붉은 평행사변형 칸) 바로 아래에 **AP 를 파란 평행사변형 칸**으로 (최대 AP 수만큼 칸, 현재 AP 만큼 참). 머리 위 AP 글자는 제거.

  - 버튼은 **같은 버튼을 다시 누르면 취소** (우클릭도 취소). 취소 버튼은 제거, 맨 오른쪽엔 모서리 둥근 정사각형 **턴 종료**만.
  - AP 는 버튼을 누를 때가 아니라 **행동을 실행할 때** 소모 (대상 클릭·자리 클릭·장착하기).
  - 스킬·자리 이동·필살기는 칸 75px, 버튼이 패널 세로 정가운데(위/아래 여백 대칭), 아이콘 글리프도 칸 정가운데. 무기 칸 바탕은 스킬과 같은 색, 위 1px 여유. 초상화 옆 안내 문구 없음.
  - 상태 이상은 슬롯 오른쪽, 채도 낮은 불투명 파란 외곽선 창 안에 **한 줄씩**: 긍정 녹색 / 부정 붉은색, 호버 시 그 줄 50% 밝게(페이드) + 설명.
    현재 상태 이상: 독려(긍정, 독려 받은 유닛의 다음 턴 끝까지), 부상(부정, 자리 이동·교체 불가 — 아직 거는 스킬 없음).
  - 사용할 수 없는 슬롯은 회색, 비용은 "-AP" (사용 불가 붉은색 / 가능 파란색).
  - 무기 3칸(주무기·보조무기1·보조무기2): 세로로 긴 칸(패널 천장까지, 무기 원화 90° 회전), 칸 사이 간격은 다른 슬롯의 절반. 클릭 → 그 위에 불투명 검은 버튼 "장착하기 AP -1". 장착 중인 무기는 노란 테두리, 클릭하면 "장착 중"(비활성).
