# 결정 로그 v1.0

## 확정
- Godot 4.7, 횡스크롤 턴제, 6인(전방/중앙/후방 2슬롯씩), 수동 전투 우선, 자동 모드 알파 이후.
- 기습/매복 선공 우선, 일반 전투 동전, 선공은 첫 라운드 최초 행동에만 적용, 이후 양 진영 속도순 및 지정된 동률 우선순위.
- 캐릭터 자기 차례에 스킬/대상 지정 및 AP 내 다중 행동. 전투 시작 최대 AP, 자기 차례 회복, 최대 AP 상한, AP 이월, 0 AP 자동 종료.
- 모든 행동 AP 소모, 무기 변경 AP 1.
- 자기 차례 캐릭터만 이동 명령 가능. 빈 슬롯 이동, 점유 슬롯 아군과 교환.
- 단순 셀 셰이딩, 미국 카툰풍, 5번 이미지 캐릭터 화풍 목표, 광원별 강렬한 원색 대조.
- 최종 수치 밸런스는 관련 시스템 구현 후 진행.

## 프로토타입 임시 설정
- 이동 AP 1, 기본 공격 AP 1 등 비용과 적 AI, 타깃/승패/동률 최종 규칙은 `PROTOTYPE_GDD_v1_0.md` 3절 참조. 언제든 변경 가능.

## 추가 확정 (2026-10-25, 프로토타입 검토 중 사용자 결정)
- 그래픽 표현은 **2D** 로 확정 (2D/3D 비교: `docs/2D_vs_3D_comparison.md`).
- 전투 카메라: 정면이 아니라 **뒤로 물러나 내려다보는 구도**. **피치 40° 유지**, 구도를 위로 옮겨 바닥이 덜 보이게(화면 중심 y 430→480), 전투 중에는 **차례 캐릭터 중심으로 2배 줌**, 차례가 바뀌면 그 캐릭터 중심으로 카메라 이동 (2026-10-25).
- 캐릭터: **실루엣 외곽선은 분명하되 얇게** (현재 0.7px), 조명 색은 반투명하게 덮지 않고 **쨍하게** 입힘 (`shaders/cel_character.gdshader`).
- 캐릭터 **림 라인(그림자 쪽 가장자리의 반대 조명색 선) 사용** 확정. 전투 중 F3 토글은 비교·디버그용으로만 유지.

- 제공 캐릭터 이름·키: **하나 176.8cm**, **니키타 168cm**, **키라 175cm**, **앨마 166cm**, **이선 178cm**, **단 185cm**. 화면 크기에 키 비율 반영.
  니키타 원화 = nikita-army(군모·밝은 회색 롱코트·의무 완장), 하나 = 곱슬 롱헤어·짙은 회색 전투복, 키라 = 군모·갈색 포니테일·짙은 전투복(왼손 주머니)·카고 팬츠.
- 배치(3대3): 아군 **키라 전열, 하나 중열, 니키타 후열** / 적군 **단 전열, 이선 중열, 앨마 후열**.
  앨마 = 금갈색 올림머리·밝은 회색 롱코트(적십자 완장, 의무병), 이선 = 짧은 갈색 머리·짙은 재킷(양손 주머니), 단 = 민머리·큰 체격·소매 걷은 재킷(양손 주머니).
- 줌인 중에도 주변 캐릭터를 **투명하게 하지 않음** (전투 불능도 어둡게만, 불투명).
- 바닥 그림자는 **캐릭터 모양** (원화 실루엣을 3D 판으로 세워 실제 광원으로 드리움). 캡슐 그림자 폐기.

- 그래픽 목표 (2026-10-25 레퍼런스 4장: 남청+주황 방, 초록+빨강 문, 보라 방, 청록+분홍 문): **장면 전체를 '주변광 색상 + 광원 색상' 두 색으로 확실하게 칠한다.**
  - 배경(3D): 재질 색은 밝기만 쓰고 구역마다 팔레트 색상으로 칠함 — 그림자 = 짙은 그림자 색, 주변광 = 채도 높은 주변광 색, 빛 = 광원 색 그대로.
    빛 영역 안의 그림자(캐릭터·소품·문짝)는 짙은 그림자 색 (`cel_3d.gdshader` palette_paint).
  - 캐릭터: **실제 3D 광원이 몸 어디에 닿는지 계산한 빛 지도**로, 닿는 부분만 광원색으로 칠함 (머리는 그늘·다리는 빛 같은 분할, 다른 캐릭터가 가리면 그 그림자 속).
    빛 없는 면은 원화 밝기를 유지한 채 주변광 색상으로 65% 물듦(선화도 같은 색상의 어두운 선), 빛 반대쪽 형태 그림자면은 그림자 색상.
    빛은 타지 않게(채널이 넘치면 색상 비율 유지), **선화와 검정은 빛을 받지 않음** (`cel_character.gdshader` v7).
- 버그 수정(2026-10-25): 캐릭터 셰이더가 텍스처색을 두 번 곱해(Godot 4 의 fragment `COLOR` 는 이미 텍스처색) 원화가 제곱만큼 어둡게 보였음 → 수정 후 원화 밝기 그대로.

- 렌더 해상도 **QHD(2560×1440) 고정**. 리그 원화는 원본의 0.5배(키 약 750px)로 잘라 QHD 표시 키(약 300px)의 2.5배 해상도 확보.

## 검증 중 (확정 아님)
- **배경 3D + 캐릭터 2D 하이브리드** (2026-10-25 적용): 배경은 3D 방을 2D 카메라와 같은 투영으로 렌더, 캐릭터 라이팅은 실제 광원 위치 기준
  (빛 쪽 얼굴·몸을 광원색으로 밝힘 + 빛이 뒤에서 오면 같은 쪽 가장자리 림 + 바닥 그림자). 캐릭터 2D(리그)는 확정 사항 유지. 이전 2D 배경은 `--bg=2d` 로 비교 가능.
- Skeleton2D 컷아웃 리그: 제공 캐릭터 1명으로 비용 테스트 중 (`docs/skeleton2d_cost.md`). 애니메이션 방식(프레임/본/혼합)은 미정.
- 외곽선 렌더 비용: 소프트웨어 렌더 기준 증가 확인, 실기기(맥북) 측정 필요.
- 눈동자 색은 조명에 묻히지 않게 **일부러 진하게 칠함**: 니키타 파랑(#4f9cff, 원화 회색을 선명하게), 하나 호박색(#ffb020). 로스터 `eye_paint` 로 변경 가능. **이선은 원화 눈 색 그대로** (`eye_paint` 없음 → 칠하지 않음).
