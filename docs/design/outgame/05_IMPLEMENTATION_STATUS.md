## 3. 구현용 임시 결정 (기획 확정 아님, 바꾸기 쉬움)

- **대원** = 전투 아군 6명 (단·키라·이선·하나·앨마·니키타). 엑셀 `대원` 시트 `전투캐릭터` 열로 연결. 성격·관계·대사는 미정 → `[테스트 대사]` 더미.
- **층** = 지상 1층 / 지하 1층 (개방) / 지하 2층(임시, 전부 잠금). 시설은 층마다 왼쪽→오른쪽 칸, 양 끝 계단으로 층 연결, **방을 지나 다니는 단면** → 잠긴 방은 통과 불가.
- **시설(더미 이름)**: 지상 1층 = 정문(외부 의뢰 출입) · 서쪽 계단 · 행정실(의뢰 게시판) · 공용실 · 식당($50) · PX($40) · 동쪽 계단 / 지하 1층 = 숙소 · 의무실 · 무기고(제작·강화·장착) · 훈련실($90) / 지하 2층 = 계단($40×2) · 창고($120) · 봉쇄 구역($200).
- **시계**: 08:00 시작, 현실 1초 = 게임 1분 (HUD 1x/4x/16x, 정지). 창이 열려 있으면 정지, 전투 중에도 정지. 오프라인 진행 없음.
- **결산**: 시작일부터 7일마다 00:00. 지원금 $100. 작업·의뢰 수익은 완료 시 미지급 → 결산 때 입금.
- **점검**: 매달 남은 날짜 중 랜덤 시각(시작 달은 4/7 08:00 이후). 점수 = 해금된 청소 구역 청결도 평균. 80↑ 만족 $60 / 50↑ 보통 $30 / 그 외 $0.
- **위생**: 초기 90, 매일 0시 1~2건 오염(건당 -20), 청소 20분 → 100. 날마다 자연 감소는 없음.
- **업무·의뢰**: 작업지시(기지 안 시설에서 일함, 반복 가능) / 외부의뢰(정문으로 나가 기지 밖 → 복귀, 1회). 성공률·위험 없음 = 고정 완료.
- **요청**: 앨마 `req_01` 수락 → 외부 의뢰 '민간인 호위' 열림. 이선 `req_02`(4/9부터) 효과 없음.
- **훈련·제작·강화**: 훈련 120분 → 훈련 단계 +1 = 전투 최대 HP +5. 제작은 비용 없이 시간만(레시피 미정). 강화 60분 → +1 = 무기 위력 +1 (최대 +5). 작업실 한 번에 하나.
- **전투 연계**: 기지에서 출전한 전투만 훈련·장비·강화 반영 (전투 규칙·AP 체계는 그대로, UnitData 복제본의 수치만). 외부 의뢰 중인 대원은 출정 불가(출정 대기 목록에서 흐리게, 진형에서 빠짐). 출정 인원 1~6명.
- **플레이어 조작**: 대원 클릭 = 선택(노란 고리·카드), 방 클릭 = 그 위치로 걷기, 더블클릭 = 뛰기(×2.2, 피로 +12/시간), 도착 후 우클릭 = 방별 행동
  (`BaseSim.room_actions`: 잠자기·쉬기·식사·청소·훈련·치료·업무·시설 창), '지시 그만두기'. 직접 보낸 대원은 다음 일정 블록까지 지시 대기. 테스트 [30].
- **계단**: 계단 칸 안에서 층마다 방향이 바뀌는 지그재그 계단 판. 대원은 아래층 계단 끝 → 위층 계단 끝으로 대각선 이동(속도 그대로), 화면에서도 계단 판 깊이에 맞춰 걸음.
- **오브젝트** (엑셀 `오브젝트` 시트): 침대 6(숙소 2층 침대 3개, 회복 12/11), 소파 2(공용실, 7), 의자(행정실·식당, 3), 의무침대 3(피로 10 + 체력 8). 한 오브젝트에 한 명. 수면은 회복력 높은 빈 오브젝트부터, 휴식은 소파·의자, 업무·식사는 의자.
- **피로도**: 0~100, 시작 20. 깨어 있으면 시간당 +2, 업무·청소·외부 의뢰 +4, 훈련 +7, 전투 +20, 식재료가 없어 굶으면 +6. **잠잘 때 오브젝트 회복력만큼만 감소** (식사는 줄이지 않음). 높을 때 불이익은 아직 없음.
- **체력·상태 이상**: 전투 결과의 아군 HP 가 그대로 기지로(쓰러지면 HP 1 + 부상), 긍정 상태는 지우고 부정 상태는 유지 → 다음 전투도 그 HP·상태로 시작. 우클릭 → `의무실로`: 상태 이상이 있으면 치료 60분(제거) → 의무침대에서 휴식(체력 8/시간)하다 가득 차면 일정으로 복귀.
- **친밀도**: 0~100, 시작 20. 하루 첫 직접 대화 +1, 요청 수락 +5, PX 선물. 아웃게임 카드에서만 표시(파스텔 노랑, 피로도 아래, '다음 대화 N').
- **PX 선물 선호** (엑셀 `PX` 시트: 기본 + 대원 이름 열, 빈 칸 = 기본): 캔커피(기본 2, 니키타 8·이선 4·키라 3·앨마 1) · 초콜릿(3, 하나 12·앨마 9·키라 5·단 1) · 가죽 장갑(5, 단 16·키라 10) ·
  문고본(4, 이선 13·앨마 6·니키타 6·단 2) · 행운 부적(4, 키라 14·하나 8) · 소시지 통조림(3, 단 11·이선 6·니키타 1). 기본 2배 이상 = 아주 좋아함, 기본보다 크면 좋아함, 작으면 별로.
- **친밀도 대화** (엑셀 `친밀도대화` 시트): 대원마다 30·50·70·90 단계(더미 대사). 기준을 넘으면 알림 + 머리 위 ♥. 클릭 대화 = 요청(!) > 안 본 해금 대화(낮은 단계부터) > 해금된 가장 높은 단계 > 기본 대사. 본 대화는 저장.
- **식당**: 식재료 시작 10끼, $20 → 12끼. 식사 블록에 식당에 있으면 3시간 단위 끼니마다 1끼 소모.
- **전투 발생**: `data/outgame/battle_rules.json` (Godot 에디터 `전투 발생` 탭). 예시 `raid_6h` = 06:00 기준 6시간마다 stage_01, 넘기기 불가. 발생 → 기지 시계 정지 + 붉은 막대 `전투 배치로`(→ 편성 → 전투 → 결과 → 기지). 대기 중엔 다른 규칙 발생 안 함, 같은 분이면 위 규칙 하나.
- **저장**: `user://outgame_save.json` — 날짜 변경·출전·저장 버튼·타이틀로 갈 때. 슬롯 1개.

## 4. 화면 (2026-10-26 갱신)

- 배경은 3D 단면 건물, 건물 바깥은 검정. 카메라는 직교(정면처럼 반듯, 방마다 같은 크기 사각형, 한 칸 ≈ 정사각형) + 18° 내려다봐 방 안 바닥이 보임. 기본 확대 = 화면 세로 9m. 확대/축소 45%~250% (휠·트랙패드 핀치·Q/E·+/-·HUD 버튼, 커서 위치 기준으로 부드럽게).
- 방마다 시설 시트 '조명'(g1~g4) 색 스폿 조명 + 하드 섀도우(방 조명만), 셀 셰이딩.
- 잠긴 방 = 단면 앞을 검은 판으로 막음 + 자물쇠·가격. 해금하면 그 방만 다시 지어 내부·조명이 생김.
- 대원은 전투와 같은 2D 캐릭터 스프라이트(프레임 애니메이션, `assets/characters/`)를 발 위치(3D)를 투영한 화면 위치에 원근 크기로 그림. 걷기·뛰기 중에는 그 대원 발자국 소리(발 닿는 프레임마다, 소리 파일이 있는 대원만). 동작: idle·walk·sit·sleep·work·clean·train·talk — 프레임이 없으면 기본 그림 한 장. 클릭 판정은 화면 좌표(방 = 단면 앞면 사각형).
- 침대·의무침대에서는 누워 자고(`sleep` 프레임, 없으면 기본 그림을 눕힘 — 머리는 베개 쪽), 소파·의자에는 앉음(`sit` 프레임, 없으면 의자 앞에 서 있음). 휴식 중엔 Zz.
- 대원 클릭 카드: 체력(붉은) · 피로도(보라) · 친밀도(파스텔 노랑) 게이지 + 상태 이상, 선물하기. 시설 창: 식당(식재료 공급) · PX(선물 구매) · 의무실(환자 목록) · 무기고(대원별 장착 3칸 + 제작·강화).
- **레벨·스킬** (2026-10-27): 출전 경험치 → 레벨 업 → 스킬 포인트. 기지 `스킬` 버튼·대원 우클릭 → 스킬 창: 왼쪽 대원 목록(스크롤) + 탭 액티브 · 패시브(각각 십자형 트리, `data/skill_tree.json` — Godot 에디터 `스킬 트리` 탭에서 노드를 직접 짬) · 신앙(`data/faith.json` — 스킬 트리 탭 → 신앙 스킬, 임시 데이터).
- **연구실·로한** (2026-10-27): 지하 1층 서쪽 끝 연구실, 연구원 로한(전투 안 함) 클릭 → 무기 연구. 엑셀 `연구` 시트, 완료 → 무기고 제작 해금. 로한이 연구실에서 깨어 있을 때만 진행.
- **출정 대기(편성) 화면** (2026-10-27): 왼쪽 대원 목록(체력·피로·친밀도·상태 이상) / 오른쪽 위 진형 후방2·중간2·전방2, 드래그 앤 드롭 배치·교환·빼기. 배치된 대원 초상화 위 말풍선 대사 (`data/outgame/sortie_lines.json`, Godot 에디터 `출정 대사` 탭).
- 규칙(BaseSim)의 좌표는 그대로 2D (칸 240px = 3.6m, 층 220px = 3.8m 로 변환) — 테스트·저장 형식 변화 없음.
